# Quickstart: 端到端验证指南

**Feature**: `specs/001-life-goal-tracker` | **Date**: 2026-08-18（Web 主面验证版）
本指南用于在实现完成后验证功能可用——每个场景对应规格的 SC/FR，作为验收演示路径。不含实现细节（见 tasks.md）。

## 前置条件

- 开发机：Windows/WSL2 + Flutter SDK（stable）；**无需 Mac、无需 Android 环境**
- 日常验证主面：**全功能 Web**（`flutter run -d chrome`）——浏览器内真实持久化（IndexedDB，刷新/重开不丢数据），导出/导入、补签、周回顾、忙碌模式等全部可走查；提醒为页内模拟；小组件等 iOS 专属能力以占位说明呈现
- iOS 专属验证（小组件/系统通知/深链）：push → Codemagic 自动构建 → **TestFlight 安装到用户 iPhone** 实机验收

## 构建与运行

```bash
flutter pub get
flutter run -d chrome                 # 日常验证主面（全功能，数据持久）
```

统计引擎与备份的纯逻辑测试脱离任何浏览器/设备、在 WSL 宿主机直接跑：

```bash
flutter test                           # R1–R9、备份格式、FrequencyVersion 口径、仓库层（drift 内存库）
```

iOS 构建即门禁——push 触发，构建绿后自动分发 TestFlight：

```bash
git push                               # codemagic.yaml → iOS 构建（含小组件扩展）→ TestFlight
```

## 验证场景

### V1. 首个目标创建 ≤ 30 秒（SC-001 / FR-001/012）

1. 首启进入引导 → 选模板"好好吃饭"（每日 3 次）→ 确认
2. **预期**：目标出现在今日视图，显示 0/3；全程 ≤ 30 秒
3. 附加：输入模糊目标"变健康" → **预期**：出现具体化建议（如"每周运动 3 次"）可一键采用
4. 验证设备：Web 本地 / TestFlight 均可

### V2. 当日打卡闭环 ≤ 10 秒（SC-002 / FR-003/004）

1. 另建两个目标（"每周锻炼 3 次"、"23 点前睡"每日 1 次）
2. 回到今日视图，逐一打卡（锻炼点击 1 次 → 显示 1/3）
3. **预期**：3 个目标完成当日打卡 ≤ 10 秒；连击、周进度即时更新；误点可当场撤销并回退
4. 全部达标后重进今日视图 → **预期**：成就态而非空白
5. Web 加验：刷新页面 → **预期**：数据完整保留（持久化非内存）
6. 验证设备：Web 本地 / TestFlight 均可

### V3. 小组件打卡 ≤ 5 秒（SC-007 / FR-016）— **TestFlight 真机**

1. iPhone 桌面长按 → 添加 Target 中组件（medium）
2. **预期**：组件显示生活电量与今日列表；点击某目标打卡按钮 → 显示 x/y +1，无需打开应用；锁屏添加 circular 电量环正常
3. 降级路径顺带验证：若后台回调受限，点击后退化为深链打开对应目标页，不得无响应
4. Web 侧对应表现：今日页显示"小组件为 iOS 专属能力"占位说明，不报错

### V4. 周结算与周回顾（FR-008 / R1、R2）

1. 开发构建中打开 设置 → Debug 时钟，跳至下周一 08:05
2. **预期**：收到晨间概要提醒（含周回顾引导）；周回顾页显示上周各目标完成率、近 4 周趋势、补签次数；某目标 <50% → 呈现教练式调整建议
3. 选择"调整频率" → **预期**：提示下周一生效，当周口径不变
4. 验证设备：Web 本地可验全流程（提醒为页内横幅模拟；系统通知呈现以 TestFlight 复核一次）

### V5. 补签与统计透明（FR-004 / R5–R7）

1. 目标详情进入历史日历，为昨日补 1 次
2. **预期**：记录带"补"标记；连击/完成率按新事实更新；周回顾呈现当期补签次数
3. 验证设备：Web 本地 / TestFlight 均可

### V6. 忙碌模式（FR-018 / R8）

1. 今日页开启忙碌模式，将"锻炼 3→1 次"，当周生效
2. **预期**：今日目标次数即时变为 1 次；列表与周回顾带"忙碌模式"标注；一键恢复后回落原频率
3. 验证设备：Web 本地 / TestFlight 均可

### V7. 备份闭环（FR-015）

1. 设置 → 导出备份 → Web 端经浏览器下载得到 `.targetbackup` 文件
2. 删除浏览器站点数据（或换浏览器）→ 导入该文件，选择"覆盖本地"
3. **预期**：目标、打卡、周回顾完整恢复，摘要显示各实体记录数一致；本地有数据时导入 → 出现"覆盖/取消"弹窗，绝不静默合并
4. 验证设备：Web 本地可验证完整闭环；iOS 分享面板行为在 TestFlight 复核

### V8. 通知降级（FR-006/007）

1. 系统设置关闭通知授权 → 回到应用
2. **预期**：全部功能正常；设置页出现"如何开启通知"说明；无报错、无反复弹窗
3. 验证设备：TestFlight 验证系统通知路径；Web 端验证页内提醒模拟的开关与到点行为
