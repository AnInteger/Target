## 阶段 C：迁移对账 + 真机合并轮

1. **迁移对账（web/测试双跑）**：构造 v2 存量库（四分支各一条：milestone+截止 / habit+daily / habit+weekly / 暂停 milestone）→ 升级启动 → 目标/打卡/记录/补签计数逐项一致；类型符合映射；今日页全可见可打卡；旧字段（频率/颜色/为什么/怎样算）零上屏（SC-003）
2. **备份互导**：旧版导出 → 新版导入（走映射）；新版导出 → 旧版导入（基础字段可用）；往返后计数一致
3. **真机合并轮（T043 用户侧动作清单，与下次构建合并）**：
   1. Codemagic 控制台手动触发 `ios-unsigned` workflow → 等构建绿 → 下载 unsigned.ipa
   2. iLoader 自签安装（覆盖装机，**不清数据**——真机存量库即 v2→v4 迁移的真实样本）
   3. 装后首启核对（迁移面）：旧目标全数出现在今日页、可打卡；详情页提醒行与原设定时间一致（08:30 档照旧）；旧版频率/颜色/「为什么」等字段不出现
   4. 视觉核对：新图标/启动屏（T028「今日之环」A 案资产首次真机亮相）、深色模式
   5. 手感核对：三 Tab 切换跟手（今日/回顾/我的）、打卡动效帧率（肉眼顺滑）
   6. 通知核对（FR-012 真机独占）：到点提醒语气正式（「今天还没有记录。」）；短期到期的「到日子了，怎么样？」询问通知；点通知落地目标详情页
   7. 结论记 `design/reviews.md`（真机轮条目）
