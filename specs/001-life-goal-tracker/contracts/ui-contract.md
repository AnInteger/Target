# Contract: 界面与导航（UI Contract）

**框架**: Flutter（go_router 路由 + Riverpod 状态），无 TabBar（极简定位：一个主屏 + 从属页）| **设计基调**: 极简、留白、温和不指责（spec Assumptions）

## 页面清单

| # | 页面 | 路由 | 核心内容与状态 |
| - | ---- | ---- | ---- |
| 1 | 今日 Today | 启动默认页 | **生活电量**为视觉核心（环 + 百分比，空态"—"）；今日目标列表（habit：名称 + x/y + 打卡按钮；milestone：进度 + 倒天数概要）；全部达标 → 成就态文案与动效；忙碌模式进行中 → 列表顶部标注 |
| 2 | 目标管理 Goals | 今日页 toolbar | 分区：活跃（≤5，含两类）/ 暂停 / 已归档；目标卡片显示连击与周完成率 |
| 3 | 创建/编辑目标 GoalEditor | 目标管理 + 空态引导 | 类型选择（习惯/里程碑）→ 模板库（好好吃饭/规律运动/早睡/屏幕休息/个人项目…，FR-012）或自定义 → 频率（每天 N 次/每周 N 次/指定日，FR-002）→ 图标/颜色；**SMART 引导**：模糊名称（"变健康"）→ 一键采用具体化建议（FR-001）；活跃已满 5 → 聚焦引导弹层（FR-011）；编辑频率提示"下周一生效"（FR-002） |
| 4 | 里程碑详情 Milestone | 目标卡片 | 步骤清单（勾选可回退）、进度 done/total、截止倒计时；过期 → 温和的"顺延/关闭"选项（US5-3） |
| 5 | 周回顾 Review | 周一晨 dailyBrief 深链 / 今日页入口 | 上周各目标完成率卡 + 近 4 周趋势 + 补签次数（透明，R6）+ 忙碌标注；反思输入框；决策三选：继续 / 调整频率（生成下周版本）/ 暂停（FR-008）；<50% 目标 → 教练式建议文案 |
| 6 | 忙碌模式 BusyMode | 今日页快捷入口 | 选择目标 → 逐个降档预览（"锻炼 3 次 → 1 次"）→ 一键开启（当周生效标注）；进行中会话 → 一键恢复（FR-018） |
| 7 | 设置 Settings | 今日页 toolbar | 每日概要时间（默认 08:00）、逐目标提醒开关与时间、备份导出/导入（FR-015）、数据风险与隐私说明、（开发构建）Debug 时钟 |

## 导航与模态

- 主栈：`Today → Goals → (GoalEditor | Milestone)`；`Review`、`BusyMode`、`Settings` 以模态浮层呈现（轻量、即进即出）
- 小组件/通知深链：`target://today`、`target://review`、`target://goal/{id}`（go_router 统一解析，research D14）

## 状态契约

| 状态 | 契约 |
| ---- | ---- |
| 空态-无目标 | 引导卡片 → 模板建目标（SC-001：≤30 秒） |
| 空态-全部达标 | 成就态（正向文案 + 轻动效），非空白列表（US2-6） |
| 离线 | 恒可用（无网络依赖），不出现加载态 |
| 通知被拒 | 功能全可用；设置页呈现"如何开启"说明，不反复弹窗（FR-007） |
| 撤销打卡 | 当次打卡 toast 内联"撤销"按钮（当日/补签均可撤销，FR-004） |
| 忙碌进行中 | 今日列表与周回顾呈现"忙碌模式"徽标（FR-018） |
| 导入冲突 | 弹窗"覆盖本地 / 取消"，绝不静默合并（FR-015） |

## 文案与语气（FR-008 的全局基调）

- 教练式、非指责：完成率 40% 呈现为"要不要调小一点？"而非红色警告；连击断裂呈现"忙就先降档，线还在"（配合忙碌模式入口）
- 生活电量低（<30%）的表达 = "该充电了"（提示照顾自己），不是"你不合格"（FR-017）
- 全部文案集中于 `lib/core/copy.dart` 文案表，语气可整体审校
