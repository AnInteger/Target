## 4. 风险与研究结论

- **范围**：≈ 003+004 两轮特性之和；FR-001 门禁分屏冻结分屏实现可降低爆炸半径。
- **删除面广**：评分链/周结算/通知列表/onboarding 在 backup、repositories、
  settings_view 均有引用，删除以 analyze 0 + 全量回归兜底（审计表 3.3）。
- **Liquid Glass 上限**：blur+saturate 在 Flutter Web 的性能需在 T303 验证；
  如掉帧，玻璃降级为半透明实底（视觉近似，令牌留降级档）。
- **iOS 26 玶璃语义**：本设计的玻璃为「iOS 26 Liquid Glass 视觉参照」的自绘近似
  （blur 24 / saturate 180% / 0.5px 白描边 + inset 高光），不依赖系统组件。
- **深色渐变**：Figma 仅浅色；深色头部渐变（暗紫系）为 agent 提案，R1 一并裁定。
