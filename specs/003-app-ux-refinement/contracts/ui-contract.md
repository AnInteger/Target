# UI Contract: 003 App 体验精修

界面结构契约（路由 / 屏区块 / 导航 / 编辑器分组）。视觉令牌真源仍为 `design/tokens.css ↔ lib/app/design_tokens.swift ↔ ios/TargetWidgets/DesignTokens.swift` 三端镜像——本特性新增令牌先改 tokens.css 再镜像。

## 路由结构（三 Tab）

```text
GoRouter
├── /onboarding                        首启引导（不变）
└── StatefulShellRoute.indexedStack    底部胶囊导航壳层（今日屏 R5 定稿几何）
    ├── 分支 0 today
    │   ├── /today                     今日页（头部：账号区 | 通知铃铛 | ＋新建）
    │   ├── /goal-editor?id=&template= 编辑器（子路由——底部导航保留，FR-010）
    │   └── /goal/:id                  目标详情（子路由——底部导航保留）
    ├── 分支 1 review
    │   └── /review                    周回顾（空态 CTA → context.go('/goal-editor') 落 today 分支）
    └── 分支 2 mine
        └── /settings                  我的（设置结构重组）
```

- 页签恰 3 枚：今日 / 回顾 / 我的（FR-001）；`/goals` 路由与 GoalsView 退役，深链兜底改落 `/today`
- 深链 `target://`：today/review/goal/{id} 映射不变；goal 无 id 兜底改 `/today`
- 弹层（非路由）：通知列表、资料编辑、补签日历、达成/续期确认——bottom sheet 层，不遮底部导航

## 今日页区块（自上而下）

1. **头部（与内容同图层、无分隔线，FR-003）**：左 = 账号区（头像环 + 昵称，tap → 资料编辑 sheet）；中 = 日期语；右 = 铃铛（角标 = 今日新增推导条目数——推导式列表无已读态，取今日日期归属的条目计数，tap → 通知列表 sheet）+ ＋（tap → /goal-editor）
2. **今日之环区**：全类型目标「今天记录了吗」0→1 圆环（D2 口径；类型微标：习惯=节律点、短期=倒计时 chip、长期=∞ 语标）
3. **目标卡列表**：图标（GoalIconCatalog）+ 一句话描述 + 类型徽章 + 今日打卡态；tap 卡 → /goal/:id；长按 → 补签日历（既有）
4. **底部**：周节奏微条（既有 R4 语言保留）

## 编辑器分组（分组折叠，FR-011）

```text
基础信息    [一句话描述输入框（40 字，placeholder 示范完整短句）]
目标类型    [长期 | 短期 | 习惯] 分段选择
  ├ 短期 → 截止日选择器（必填）+ 倒计时预告
  └ 习惯 → 提醒开关 →（开）频率档 [一天一次|三天一次|一周一次] + 时间选择器
图标        [GoalIconCatalog 九宫格（≥9 类滚动分区）]（无颜色步，FR-015）
保存        常驻底部（导航条上方）
```

- 全程无「多久做一次/次数/多少天」问答、无为什么/怎样算字段（FR-012/014）
- 编辑既有目标：同构（类型可改，改型时截止/提醒区联动显隐）

## 我的页结构（主流设置式，FR-009）

```text
账号卡        头像 + 昵称 + 「编辑」（→ 资料编辑 sheet）
分组·通知     提醒总开关（值行）｜每日简报时间（值+箭头）｜按目标提醒（二级列表）
分组·目标     活跃目标数（值+箭头 → 今日页）｜补签说明（只读）
分组·数据     备份与导出（箭头）｜导入（箭头）
分组·关于     版本（值）｜隐私脚注（既有 R2 语言）
```

行形态：图标 + 标题 + 行尾（值 | 开关 | 箭头）；深浅两态令牌对齐。

## 回顾页（R4 轮）

- 空态：竖直居中、引导文案 + 「新建目标」主按钮 → /goal-editor（≤1 交互，FR-007）
- 三屏大标题左缘缩进与竖直基线统一（今日/回顾/我的，FR-008）——以今日页为基准出对齐规格

## 通知列表（sheet，推导式 D6）

- 行：类型图标 + 标题 + 相对时间；按天分组、时间倒序
- 类型：今日/明日提醒时刻、近 7 天成就、streak 里程碑、短期到期询问（tap → /goal/:id）
- 空态：一句话说明「这里会出现你的提醒和值得记下的时刻」

## 原型评审门禁（002 惯例延续）

HTML 原型先行：screen-today(R5)/screen-editor(R2)/screen-review(R4)/screen-settings(R3) 重构 + screen-goals 归档声明；每屏典型/边界（空态/深色）画板，用户浏览器裁决记录 design/reviews.md 后方可动 Flutter（对应 FR-001~015 的实现任务门禁）。
