# 006 · App v3 全面重构：两 Tab IA + 富记录模型 + iOS 原生风

- **Status**: Approved（原型 8 屏冻结 2026-09-08 R3「过」；实现中 · feat/v3-app-redesign）
- **日期**: 2026-09-08
- **前置**: 004（v2 换装）· 2026-08-26 产品结构重构 phase 1（目标管理）
- **设计基准**: 用户 Figma Make 原型 7 屏（2026-09-07 定稿参照图）+ 本特性补画屏

## 1. 背景与定位

用户重新设计产品：App 从「柔彩仪表盘 · 三 tab · 轻打卡」整体重构为
「iOS 原生风（局部 Liquid Glass）· 两 tab · 富记录」。核心叙事从
「每日打卡完成度」转向「为目标留下有内容的进展记录」——副标题即产品主张：
「把想做的事，慢慢变成经历。」

**本次重构不迁移存量数据**：schema 直接重建、清库换新；备份按新模型定义
单一新格式（旧格式文件不再支持导入）。

## 4. 信息架构

```text
目标（tab 1）：置顶大卡 + 其他目标列表 + 空态；新建入口（头部 ＋）
动态（tab 2）：周投入统计 + 里程碑汇总 + feed + 筛选 + 日历投入
push 页：目标详情（时间线 + 记录 CTA + ⋯ 生命周期）
        里程碑页（接下来/已达成 + ⋯ 管理）
        编辑器（添加/编辑目标 sheet，完整字段）
        设置（与我的合并；入口=动态页头部）
sheet：记录进展（全局记录钮/详情 CTA 共用）
```

底部 Liquid Glass 胶囊：左 = 目标|动态 双 tab，右 = 记录钮。
首启路由 `/goals`；`/today` `/review` `/onboarding` `/profile` `/goals-all` redirect 兜底。

## 5. 需求（FR）

- FR-001 原型门禁：任一屏评审结论为「通过」前，该屏不进实现（沿用 002 契约）。
- FR-002 记录模型：ProgressRecords = title（必填 ≤40 字）/ body（可选 ≤500 字）/
  durationMinutes（可选）/ day + createdAt / isBackfill / kind（normal|milestoneAchievement）
  / milestoneId（可选关联）。
- FR-003 里程碑达成流：标记达成（里程碑页 ⋯）→ doneAt 落库 + 生成
  kind=milestoneAchievement 记录（title=达成：里程碑名，body 可附一句话）；
  撤销达成同时撤除该记录。
- FR-004 置顶：goals.pinned；置顶区「编辑」进入「编辑置顶」模式（健康式：置顶行=移出「−」+拖拽手柄「≡」，其他目标行=图钉加入，右上蓝 ✓ 完成）；非置顶经
  菜单「置顶」入组；已暂停/归档目标不出现在目标页默认视图（状态筛选可见）。
- FR-005 动态统计：周投入=Σ durationMinutes（无时长记录计 0 分钟但计记录数）；
  里程碑汇总=本周达成数/全部待达成数；feed=时间倒序混排（普通+达成）。
- FR-006 （R2 退役）筛选条件不再提供：动态页「日历」入口（原筛选位）点击直达日历视图。
- FR-007 日历：范围所有日期（月导航）；月历每格圆环 = 当日投入 / 当月峰值；点选日显示当日摘要。
- FR-008 编辑器：名称必填即可保存；日期/节奏为属性行（值+选择器 sheet，R2 去「时间设置」分组）；提醒/里程碑全可选互斥自由组合；
  节奏 = phase 1 frequency_pattern 语义；保存成功返回来源页。
- FR-009 提醒：逐目标开关+时刻+频率档；合并设置页提供全局总开关（关=全量取消）。
- FR-010 备份：格式 v7（新 schema 全字段）；导出/导入往返；恢复冲突显式确认覆盖。
- FR-011 令牌三端同步：design/tokens.css ↔ lib/app/design_tokens.dart ↔
  ios/TargetWidgets/DesignTokens.swift，一次提交内同步 + 契约测试。
- FR-012 深色：全屏浅深成对走查（正文对比度 ≥4.5:1，沿用 005 口径）。
- FR-013 语域：沿用 FR-021 正式语域；新文案以 Figma 定稿为基准。
- FR-014 长按菜单：目标卡管理菜单 = 长按弹出（无 ⋯ 按钮）；详情 ⋯ 与里程碑 ⋯ 保留（R2）。
- FR-015 设置入口：动态页头部（人形钮，R2 定稿）；字体 = 苹果原生优先（SF/PingFang，不内嵌）+ 标题族字重 600（R2）。

## 6. 边界（不得违反）

- 不恢复轻打卡一键语义（快捷路径仅 = 预填目标的记录 sheet）。
- 不恢复互斥目标类型 / 独立下一步计划（2026-08-26 边界延续）。
- 记录 sheet 不承担规划编辑（不新增/编辑里程碑，只关联）。
- 不做媒体附件（图片/语音）——原型中的按钮已移除。
- 不迁移存量数据、不兼容旧备份格式。
- 通知列表/铃铛/onboarding 不回潮。

## 7. 验收场景（详见 quickstart.md）

1. 空 App 首启 → 空目标页（无引导）→ 新建目标（只填名称）→ 落库置顶 → 记录进展（标题）→ 动态页可见。
2. 里程碑：添加（含描述）→ 标记达成（附一句话）→ 详情时间线橙色节点 + feed「达成：…」+ 汇总计数变化。
3. 筛选/日历：切「最近 7 天」→ 汇总卡数值正确；日历点选日 → 当日摘要正确。
4. 生命周期：暂停目标 → 目标页默认视图隐藏（筛选可见）→ 记录 sheet 目标切换不列出 → 恢复回归。
5. 备份：导出 → 清库 → 恢复（冲突确认）→ 全字段往返一致。
6. 深浅双主题全屏走查 + 令牌契约测试 + `flutter analyze` 0 + `flutter test` 全绿。
