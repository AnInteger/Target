按特性推进阶段的可执行验证场景。功能回归底线沿用 [001 quickstart](../../001-life-goal-tracker/quickstart.md) 的 V1–V8（FR-017：新信息架构下全过，允许入口位置等价调整）。

## 前置

```sh
export PATH="/home/sunxing/development/flutter/bin:$PATH"
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```

无 Mac 环境；iOS 真机经 Codemagic 手动触发（`ios-unsigned` → unsigned.ipa → iLoader 自签装机；无 TestFlight 链路）。Web 为本地全功能验证面。真机轮次与本特性完成后的构建合并（新图标/启动屏同批验证）。

## 阶段 C：迁移对账 + 真机合并轮

1. **迁移对账（web/测试双跑）**：构造 v2 存量库（四分支各一条：milestone+截止 / habit+daily / habit+weekly / 暂停 milestone）→ 升级启动 → 目标/打卡/记录/补签计数逐项一致；类型符合映射；今日页全可见可打卡；旧字段（频率/颜色/为什么/怎样算）零上屏（SC-003）
2. **备份互导**：旧版导出 → 新版导入（走映射）；新版导出 → 旧版导入（基础字段可用）；往返后计数一致
3. **真机（与下次构建合并）**：Codemagic 手动 `ios-unsigned` → iLoader 侧载 → 核对：新图标/启动屏（T028 资产首次真机亮相）、三 Tab 手感、通知到点语气、打卡动效帧率（FR-012 真机独占项）
