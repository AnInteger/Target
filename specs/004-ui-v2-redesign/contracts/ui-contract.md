## 今日页区块（自上而下）

1. **头部**：中文「星期, 日期」小字 + 大标题「今日」；右上头像（tap → `/settings`）；同一连续图层无分隔线
2. **三大类健康度环**（spec US2 / health-score.md）：三同心嵌套环，健康/习惯/目标各一环各一色；环分=减分制口径；类内零活跃 → 该环无数据态；全库零活跃目标 → 环区让位空态
3. **关注卡轮播**（spec US3）：每活跃目标一张主色大卡（状态标签 + 目标名 + 一句话描述 + 主行动按钮 → 该目标记录动线 + 辅助信息行）；横向滑动（露边 affordance）；卡序=最近互动优先；轮播区尾/角「查看全部」→ `/goals-all`；暂停/删除实时移出；单目标退化单卡
4. **空态**（零活跃目标）：新建引导 CTA（中央＋同级动线）

## 回顾页区块（自上而下，spec US5 / D9）

1. **头部**：小字 PERFORMANCE 语义位 + 大标题「回顾」+ 周切换（日历入口，往周实时派生）
2. **周平均**：完成率环 + 环比上周（上周无数据 → 「无可比较」）
3. **每日活动**：本周七天圆点行（M-S 语义），按当日完成度着色，未来日不呈完成态
4. **本周目标**：目标名 + 线性进度 + 百分比；「查看全部」入口
5. **空态**：引导文案 + 「新建目标」CTA → `/goal-editor`

## 初始屏（/onboarding 重做，D7）

纯深底 + 品牌图形 + 一句中文主张（正式语域）+「开始使用」主按钮 → `/today`；`onboardingCompleted` 机制不变；MUST NOT：注册/登录/条款/社交证明。
