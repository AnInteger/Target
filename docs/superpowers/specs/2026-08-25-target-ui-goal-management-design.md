# Target UI 与目标管理设计规格

日期：2026-08-25  
状态：设计已确认，等待书面规格审核

## 1. 背景

当前实现主要存在以下问题：

- 首页顶部和任务卡片下方留白过多，健康状态缺少完整卡片层级，横向目标卡片之间没有间距。
- 首页同时承担状态、行动与回顾，但信息归属不清；得分、下一步计划和建议彼此混杂。
- “我的”页面把个人中心与全部设置混在同一页，透明背景导致浅色卡片落在深色页面上。
- 新建目标页字段重复，图标只有视觉含义、分类含义不清，长期、短期、习惯共用同一组字段。
- 现有评分仅根据固定七天内是否有记录扣分，分布范围过窄，无法解释目标的推进节奏、下一步清晰度或截止风险。

本次设计采用已经确认的“参考稿强化”视觉方向：保留大状态卡和大目标卡的识别度，使用更清晰的层级、留白、阴影和动态表单，同时建立可解释的目标状态模型。

## 2. 设计目标

1. 首页同时支持“现在要做什么”和“最近推进得怎么样”。
2. 每个目标卡片能够回答：这是什么、现在处于什么状态、最近完成了什么、下一步是什么、何时到期、如何记录。
3. 评分只使用可验证的目标数据，不推断用户的情绪、健康状况、工作强度或生活原因。
4. 建议解释指标原理、当前事实和可执行动作，而不是只给一句评价。
5. 浅色和深色模式分别形成完整主题，不出现透明页面叠加造成的混色。
6. 新建目标保持单页、低负担，并随目标类型显示必要字段。

## 3. 非目标

- 不引入情绪、精力、压力或工作负荷等用户自评数据。
- 不进行医学、心理健康或因果诊断。
- 不根据一个分类的低分直接改变另一个分类的数学得分。
- 不在本阶段加入徽章、等级、社交排行或复杂游戏化。
- 不要求用户在创建目标时一次性完成完整里程碑计划。

## 4. 信息架构

### 4.1 首页

首页按以下顺序纵向滚动：

1. 日期、页面标题、通知和个人入口。
2. 目标状态卡。
3. 关注目标横向卡片。
4. 进展趋势。
5. 需要关注的目标列表。
6. 底部主导航。

一屏显示不完时允许自然下滑，不通过拉大固定容器制造空白。

### 4.2 我的与设置

“我的”是轻量个人中心，不是设置清单：

- 个人资料卡。
- 进行中目标、本月完成里程碑、已归档目标三个静态概览。
- 目标管理和分类管理入口。
- 独立设置入口。

“回顾”负责趋势、历史记录和阶段总结。“我的”不重复折线图、分类得分或最近动态。

设置使用传统分组列表：偏好、通知、关于。外观模式点击后从底部弹出“跟随系统、浅色、深色”选择面板。

### 4.3 新建目标

新建目标是单页动态表单，顺序固定为：

1. 目标名称。
2. 目标类型。
3. 目标图标与自动分类。
4. 类型专属设置。
5. 可跳过的下一步计划。
6. 创建目标按钮。

不显示顶部目标模板、动机或描述字段。

## 5. 首页设计

### 5.1 目标状态卡

- 使用独立白色卡片承载状态圆环和分类值，形成明确边界与轻阴影。
- 圆环中心显示“目标状态”，不展示一个缺乏解释的综合总分。
- 首页保留三个状态视角：健康、习惯、目标。它们是独立视角，不相加，也不互相扣分。
- 健康视角聚合被归入健康领域的目标；习惯视角聚合习惯类型；目标视角聚合长期和短期类型。目标可能同时出现在领域视角和类型视角中，因此三条线不能求和。
- 其他领域分类用于目标组织、筛选和更细的回顾，不强行全部塞进首页状态卡。

### 5.2 关注目标卡

每张卡片必须展示：

- 目标名称。
- 当前状态标签。
- 目标类型。
- 目标图标。
- 截止或目标日期；无日期时明确显示“长期推进”。
- 最近完成的一项里程碑或最近一次习惯记录。
- 下一项里程碑或下一次行动。
- 记录进展按钮。
- 当前推进周期。

横向轮播规则：

- 卡片之间保留 12–16dp 间距。
- 下一张卡片只露出窄边，提示可以横滑，但不能与当前卡片相连。
- 卡片高度由内容决定，避免下方出现大段空白。
- 页面指示器紧跟卡片，不占据单独的大高度区域。

### 5.3 进展趋势

- 标题使用“进展”，右侧显示时间范围，例如“近 7 天”。
- 不用分割线列出三个分数。
- 在同一卡片内展示健康、习惯、目标三条时间趋势线和当前值。
- 横轴必须是真实日期，不能把三个分类值作为连续数据点连接。
- 默认显示最近七天；回顾页可以提供更长时间范围。
- 当某个分类需要解释时，在分类名称旁显示感叹号。点击后展开对应建议。
- 颜色映射稳定，并同时使用文字标签，不能只依赖颜色表达分类。

### 5.4 需要关注

这里只展示需要用户采取动作的目标，不展示得分说明。

每项使用独立卡片而不是大容器内的分割行，并包含：

- 该目标真实图标，而不是统一的占位字符。
- 目标名称。
- 一句客观原因。
- 原因标签，例如“待规划”“节奏中断”“临近截止”。
- 一句直接行动，例如“确认下一步计划”“恢复一次即可”“检查完成路径”。
- 进入目标详情的箭头。

卡片使用图标对应的柔和背景色、统一圆角和轻阴影。装饰色只用于图标和原因标签，不大面积填充列表卡片。

## 6. 目标、里程碑与记录模型

### 6.1 目标类型

- 长期目标：持续推进，目标日期可选，默认推进周期 14 天。
- 短期目标：截止日期必填，默认推进周期 7 天。
- 习惯：执行频率必填，默认无结束日期。

用户可以修改默认推进周期。设置页的默认值只影响以后创建的目标，不批量改变已有目标。

### 6.2 里程碑

- 长期和短期目标拥有手动排序的里程碑列表。
- 一个目标可以没有里程碑；此时 UI 派生“待规划下一步”状态，不创建虚假的占位里程碑。
- 当前里程碑完成后，如果没有后续里程碑，首页显示“确认下一步计划”，并进入需要关注列表。
- 习惯不使用里程碑推进，使用执行频率、今日行动和记录连续性。

### 6.3 记录进展

记录进展与完成当前里程碑放在同一个面板中：

1. 用户填写本次进展。
2. 可选勾选“同时完成当前里程碑”。
3. 完成后可以填写下一步建议或下一项里程碑。
4. 下一步允许为空；为空时进入“确认下一步计划”状态。

记录必须保存时间、目标、文本、是否完成里程碑和关联里程碑。保存失败时保留用户输入，并提供明确重试动作。

## 7. 图标与自动分类

创建时用户只需要选择目标图标。系统通过确定性的图标映射推断领域分类，并立即显示“自动归入：分类名称”。用户可以点击分类名称更正，手动更正优先于自动推断并持续保存。

图标选择器采用两层结构：

- 页面首屏展示 6 个最近使用或常用图标，以及一个“更多”入口。
- “更多”打开底部图标选择器，按健康、学习、职业、兴趣、关系、财务等领域分组展示。
- 第一版提供不少于 30 个内置图标，不增加网络图片依赖。
- 每个图标必须有中文语义名称，供无障碍朗读和后续搜索使用。
- 图标映射表必须单独维护，不能散落在页面判断代码中。

选择图标后立刻刷新推断分类；更正分类不强制改变图标。

## 8. 评分模型

所有组成分标准化为 0–100。目标得分只描述“目标管理状态”，不代表个人价值、身体健康或心理健康。

### 8.1 长期目标

`长期目标得分 = 推进节奏 × 60% + 下一步清晰度 × 40%`

### 8.2 短期目标

`短期目标得分 = 推进节奏 × 40% + 下一步清晰度 × 30% + 截止缓冲 × 30%`

截止缓冲使用剩余天数与推进周期的客观比值：

- 已逾期：0。
- 剩余时间不超过一个推进周期：40。
- 大于一个且不足两个推进周期：70。
- 至少两个推进周期：100。

该值只反映时间缓冲，不宣称完成概率。

### 8.3 习惯

`习惯得分 = 当前频率完成度 × 80% + 行动清晰度 × 20%`

当前频率完成度为当前频率窗口内实际完成次数除以计划次数，最高为 100。目标名称作为默认习惯行动；用户另行确认下一次行动时，以该行动为准。

### 8.4 推进节奏

设目标推进周期为 `C`，距离最近一次有效进展的时间为 `T`：

- `T ≤ C`：100。
- `C < T ≤ 2C`：70。
- `2C < T ≤ 3C`：40。
- `T > 3C`：0。

新目标在第一个推进周期内享有宽限，推进节奏为 100。

### 8.5 下一步清晰度

- 存在明确的下一项里程碑或下一次行动：100。
- 没有下一步，或刚完成当前里程碑但未确认下一步：40。

允许创建没有第一步的目标，但该目标会进入需要关注列表。使用 40 而不是 0，避免把“尚未规划”错误解释为完全失败。

### 8.6 聚合与分段

- 聚合分为对应视角下所有进行中目标的等权平均。
- 已归档、已取消和已完成目标不参与当前分数。
- 没有进行中目标时显示“暂无数据”，不显示 0 分。
- 80–100：稳定推进。
- 60–79：需要校准。
- 40–59：优先调整。
- 0–39：建议重新规划。

同一个目标可能出现在不同观察视角中，但每个视角独立计算；不存在数学上的跨分类加减分。

## 9. 专业建议

建议采用固定三段结构：

1. 指标原理：解释该指标观察什么，以及为什么值得关注。
2. 当前解读：只描述用户数据中已经发生的客观事实。
3. 行动建议：给出一个优先级明确、负担可控的下一步。

首页只显示 2–3 行摘要和“了解原因”。详细内容在展开区域或底部面板中显示。

建议由“当前分段 + 主要损失项”选择。例如目标得分下降且清晰度损失最大时，优先建议确认一个下一步，而不是要求增加打卡次数。

允许生成跨分类叙述，例如“多个分类在同一时期放缓”；不得写成“因为你最近加班”或“这说明你的情绪健康下降”。没有用户自评或外部数据时，不能推断原因。

专业依据包括明确目标与反馈、执行意图、自主性支持、目标调整和恢复体验等研究，但文案必须转译为日常目标管理语言，不堆砌学术术语：

- Locke 与 Latham，目标设定理论综述：<https://www-2.rotman.utoronto.ca/facbios/file/09%20-%20Locke%20%26%20Latham%202002%20AP.pdf>
- Gollwitzer 与 Sheeran，执行意图元分析：<https://doi.org/10.1016/S0065-2601(06)38002-1>
- Ryan 与 Deci，自我决定理论：<https://www.selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf>
- Wrosch 等，目标调整：<https://journals.sagepub.com/doi/10.1177/0146167203256921>
- Sonnentag 与 Fritz，恢复体验：<https://pubmed.ncbi.nlm.nih.gov/17638488/>

## 10. 我的与设置设计

### 10.1 我的

- 固定使用当前主题的完整页面背景，不使用透明 Scaffold。
- 个人资料卡位于顶部。
- 三个概览值只提供数量，不提供趋势：进行中、本月里程碑、已归档。
- 目标管理、分类管理使用传统图标行。
- 设置作为独立入口放在应用分组。

### 10.2 设置

- 页面使用传统分组列表和统一行高。
- 主列表只显示当前值和进入箭头，不把多个互斥选项直接展开。
- 外观模式使用底部选择面板；当前选择显示勾选。
- 通知与提醒、每日概要时间、按目标提醒保留独立入口。
- 默认推进周期显示“短期 7 天 / 长期 14 天”。

## 11. 新建目标设计

### 11.1 共通字段

- 目标名称必填。
- 目标类型必填。
- 目标图标必填；分类由图标推断并允许更正。
- 不提供模板、动机和描述。
- 第一项计划选填。

### 11.2 动态字段

长期目标：

- 目标日期选填。
- 推进周期默认 14 天。
- 第一个里程碑选填。

短期目标：

- 截止日期必填。
- 推进周期默认 7 天。
- 第一个里程碑选填。

习惯：

- 执行频率必填。
- 开始日期默认为今天。
- 结束日期选填。
- 第一次行动选填。

切换类型时保留每种类型已经输入的临时值，避免用户误触后丢失。保存时只提交当前类型相关字段。

## 12. 主题与视觉规范

- 浅色模式是首要验收基线，深色模式单独适配。
- 页面背景、卡片、弹层、文字、分割线和阴影全部使用语义颜色令牌。
- 禁止根页面透明背景与固定黑色背景混用。
- 卡片圆角保持 20–24dp，输入框约 16–18dp；圆角层级随容器大小递减。
- 主要页面水平边距 18–20dp，卡片间距 12–16dp。
- 阴影轻量，只用于区分背景和主要卡片，不让所有列表行漂浮。
- 主要操作使用蓝色；健康、习惯、目标等分类色保持稳定。
- 系统文字缩放后不能产生截断；重要控件最小触达区域为 44×44dp。

## 13. 空状态、错误与边界

- 没有目标：状态显示暂无数据，并提供创建目标入口。
- 没有下一步：显示“待规划下一步”，进入需要关注列表。
- 没有进展历史：趋势图显示空状态，不绘制虚假水平线。
- 截止日期早于今天：阻止保存并在字段下方说明。
- 分类推断失败：使用“未分类”，允许用户手动选择，不阻止保存。
- 图标资源不可用：回退到通用目标图标，同时保留语义标签。
- 记录或创建保存失败：保留输入，显示重试；不能静默丢失内容。
- 通知权限未开启：设置页显示说明和进入系统设置的动作，不伪装为已开启。

## 14. 数据迁移

- 现有目标根据原类型和图标迁移到新的类型、图标和自动分类字段。
- 没有推进周期的短期目标设为 7 天，长期目标设为 14 天。
- 现有里程碑按当前显示顺序补充稳定排序值。
- 没有下一步的活跃目标派生为待规划状态，不创建数据库占位记录。
- 新评分启用前保存旧评分版本号，避免历史趋势把不同算法直接连成同一条线。趋势图在算法切换点显示“评分规则已更新”。

## 15. 测试与验收

### 15.1 逻辑测试

- 三种目标评分权重和分段边界。
- 新目标宽限期。
- 推进周期各阈值。
- 截止缓冲各阈值和逾期情况。
- 无活跃目标返回暂无数据。
- 图标自动分类和手动覆盖。
- 完成里程碑但下一步为空时派生待规划状态。
- 类型切换保留草稿且只保存当前类型字段。

### 15.2 组件测试

- 首页在 320、375、430dp 宽度下无溢出。
- 卡片轮播存在可见间距和下一张提示边。
- 趋势图显示真实时间轴、三条稳定映射的线和无数据状态。
- 感叹号可通过键盘和屏幕阅读器访问并展开建议。
- 需要关注列表使用目标真实图标。
- 外观底部面板正确回填当前值。
- 图标“更多”面板可滚动、可选择、可朗读。
- 新建页三种类型的动态字段正确切换。

### 15.3 主题与回归

- 分别截图测试浅色、深色和跟随系统。
- 验证“我的”和设置页不存在黑色底与浅色卡片错误混合。
- 验证文字放大、长目标名称、空里程碑、无截止日期和通知权限关闭状态。
- 保留已有目标增删改查、记录、提醒和回顾功能。

## 16. 实施边界

实施应按以下独立模块推进：

1. 目标模型、迁移与评分服务。
2. 首页状态卡、目标轮播、进展趋势和需要关注列表。
3. 记录进展与里程碑流转。
4. 我的、设置与主题修复。
5. 新建目标动态表单、图标选择器和自动分类。
6. 建议内容与展开交互。

模块之间通过明确的领域模型和只读视图数据连接，页面不直接复制评分或分类规则。
